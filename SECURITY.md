# Security Policy

## Supported versions

| Version | Supported |
|---|---|
| main | Yes |

Only the `main` branch receives security fixes. Projects generated from this
template are in scope: apply upstream fixes and keep your generated project
up to date.

## Reporting a vulnerability

Prefer GitHub Private Vulnerability Reporting: open a private advisory via the
repository's "Security" tab. If that is unavailable, email
security@ostara-labs.com.

Please do not open public issues for vulnerabilities.

## Response SLA

| Step | Target |
|---|---|
| Acknowledgment | <= 48 hours |
| Status update | <= 7 days |
| Fix target | <= 90 days |

## Scope

This policy covers this repository and any project generated from it.
